# POM-RX Wallet Guard

Wallet Guard is one POM-RX application profile under Blockchain and digital assets, with a cybersecurity overlap.

Target controlled path:

```text
controlled dApp
  -> trusted request capture
  -> normalized EVM intent
  -> policy / preflight
  -> Witness
  -> exact single-use Gate
  -> test wallet/provider
  -> independent observation
  -> reconciliation
```

The first acceptable demonstration must prove that a dangerous approval/signature is denied before forwarding while an explicitly allowed control request can be forwarded once and reconciled. No real funded wallet or uncontrolled malicious site belongs in this directory's first prototype scope.
